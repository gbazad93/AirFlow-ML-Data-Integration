# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Behaviour that helps build a positive environment:

- Being welcoming to newcomers and patient with beginner questions
- Giving and gracefully accepting constructive feedback
- Focusing on what is best for the project and the people using it

Behaviour that is not acceptable:

- Harassment, insults or derogatory comments
- Publishing someone else private information without permission
- Sustained disruption of discussions or code review

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests and discussions, and in any public space where someone is representing the project.

## Enforcement

Report unacceptable behaviour by opening an issue or by contacting the maintainer through their GitHub profile. Reports are reviewed and handled confidentially. Maintainers may edit or remove comments, commits, issues and pull requests that do not follow this Code of Conduct, and may block contributors for repeated or severe violations.
